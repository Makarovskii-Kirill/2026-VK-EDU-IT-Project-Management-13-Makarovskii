### Hiring Plan

| Роль | FTE | Зона ответственности |

| Product Manager | 1.0 | Бэклог, приоритеты, общение с пилотным заказчиком |
| Tech Lead | 1.0 | Архитектура on-premise, стыковка NLP и Backend, ревью кода |

| Frontend Middle | 1.0 | Admin SPA, встраиваемые виджеты в 1С |

### Development Framework — Scrum

1. **Высокая неопределённость требований.** Короткие спринты по 2 недели позволяют проверять гипотезы на пилотном заказчике и быстро корректировать курс.

2. **MVP режется на вертикальные срезы.** Каждый спринт: классификация → маршрутизация → интерфейс в 1С.

3. **B2B-внедрение идёт параллельно.** Scrum для разработки ядра, Kanban для задач внедрения у конкретного заказчика.

### Team Rituals

| Ритуал | Цель | Частота |
|---|---|---|
| Daily Standup | Синхронизация, блокеры | Ежедневно, 15 мин |
| Sprint Planning | План на спринт, цели | Раз в 2 недели, 1.5 часа |
| Backlog Refinement | Оценка задач на будущее | Раз в неделю, 1 час |
| Sprint Review | Демо инкремента пилоту | Раз в 2 недели, 1 час |
| Retrospective | Улучшение процессов | Раз в 2 недели, 1 час |
| NLP Sync | Метрики модели, план дообучения | Раз в неделю, 30 мин |
| Встреча с заказчиком | Ход пилота, фидбек, срочные нужды | Раз в неделю, 45 мин |
