# Практическое задание №4



### C4 — Уровень 1. Контекст

Система разворачивается в закрытом контуре заказчика и встраивается как надстройка в его 1С. Она читает входящие письма, классифицирует их с помощью ИИ и маршрутизирует задачи на сотрудников.

**Кто и что взаимодействует с системой:**

- **Сотрудник бэк-офиса** — получает готовые заявки в интерфейсе 1С, проверяет предзаполненные ИИ данные, подтверждает или корректирует.
- **Руководитель отдела** — смотрит дашборд с метриками: поток, загрузка, просрочки, точность ИИ.
- **IT-администратор заказчика** — разворачивает ядро, настраивает коннектор к 1С, управляет доступом, следит за логами.
- **AI-инженер** — периодически дообучает NLP-модель на новом датасете заказчика (по защищенному каналу или через обновления).
- **Корпоративная почта** — источник входящих писем и документов для обработки.
- **1С заказчика** — целевая среда, куда встраивается интерфейс системы и где создаются итоговые документы.
- **SMTP-сервер** — для отправки уведомлений внутри компании.

### C4 — Уровень 2. Контейнеры

Все контейнеры упакованы в Docker и поднимаются через Docker Compose в контуре заказчика.

- **Admin SPA** — веб-интерфейс для IT-администратора. Развертывание, коннектор к 1С, роли, просмотр логов.
- **Dashboard SPA** — дашборд руководителя. Метрики, SLA, загрузка, точность ИИ.
- **API Backend (FastAPI)** — основной бэкенд. Обрабатывает запросы от SPA, управляет заявками, отдает метрики.
- **NLP Worker** — отдельный сервис для инференса NLP-моделей. Получает письма, возвращает классификацию, извлеченные реквизиты, уверенность. Работает асинхронно через очередь, так как инференс требует GPU/CPU-времени.
- **PostgreSQL** — основная база данных. Хранит заявки, пользователей, роли, логи аудита, эталонные датасеты.
- **Redis** — очередь задач для NLP Worker (письмо пришло → задача на классификацию) и кэш для дашборда, чтобы не перегружать БД.
- **MinIO** — объектное хранилище для эталонных датасетов и архивов вложений.

**Контур заказчика:**

- **1С** — в него встроены UI-компоненты CogniFlow (через нативные виджеты или iframe).
- **Почтовый сервер** — источник писем (IMAP/POP3 или вебхуки).
- **SMTP-сервер** — уведомления.
