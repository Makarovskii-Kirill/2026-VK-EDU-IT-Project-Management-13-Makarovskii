## 3. Детализация требований

- **US-11 — Развертывание в закрытом контуре**
- **US-2 — Просмотр оригинала и предзаполненной карточки**

---

### US-11 — Развертывание ИИ-ядра в закрытом контуре заказчика

#### Функциональные требования

- Система поставляется в виде Docker-образа, который может быть загружен на сервер заказчика без доступа в интернет. 
- Установка должна запускаться единым скриптом, который проверяет наличие Docker и необходимых ресурсов, а затем разворачивает все микросервисы. 
- Конфигурационный файл `.env` позволяет задать параметры подключения к 1С и почтовому серверу без пересборки образа. 
- После запуска система должна быть доступна по внутреннему URL. 
- В случае сбоя развертывания, скрипт выводит лог ошибок на экран без зависания, с указанием конкретного шага, на котором произошел сбой. 
- Администратор должен иметь возможность обновить ИИ-модель, загрузив новый файл модели через админ-панель, без полной переустановки. 

#### Нефункциональные требования

- Время развертывания на чистом сервере не должно превышать 15 минут. 
- Все пароли и ключи API должны храниться в зашифрованном виде. 
- Система должна сохранять работоспособность при отключении интернета. 
- Архитектура Docker должна поддерживать горизонтальное масштабирование NLP-моделей. 
- Ядро должно стабильно работать на ОС. 

---

### US-2 — Просмотр оригинала письма и предзаполненной карточки документа

#### Функциональные требования (ФТ)

- При открытии заявки в интерфейсе 1С, форма разделяется на две панели: слева — предпросмотр оригинального письма/PDF, справа — карточка создаваемого документа (Счет, Договор, Акт, Заявка). 
- В левой панели вложения должны рендериться нативно (PDF, JPG, PNG) без необходимости скачивать файл на диск. 
- Поля в правой панели, которые ИИ извлек из текста, должны быть предзаполнены и подсвечены (например, легкий желтый фон), чтобы пользователь видел, что данные внесены автоматически. 
- При клике на предзаполненное поле, система должна подсветить область текста в оригинале письма/PDF, из которой был взят этот реквизит. 
- Если ИИ не смог извлечь значение (низкая уверенность), поле остается пустым и помечается красной обводкой для обязательного ручного заполнения. 
- Загрузка интерфейса не должна блокировать работу пользователя с другими вкладками 1С. 

#### Нефункциональные требования (НФТ)

- Время открытия формы заявки (загрузка письма + выполнение NLP-инференса + рендеринг) не должно превышать 2 секунды. 
- Интерфейс должен соответствовать интерфейсу 1С, чтобы у пользователя создавалось ощущение нативной функции, а не стороннего сервиса. 
- При ошибке загрузки вложения, правая панель все равно должна отобразить все текстовые метаданные, которые удалось извлечь из тела письма. Система показывает плейсхолдер «Ошибка загрузки файла» вместо левой панели. 
- Предпросмотр документа осуществляется на стороне клиента, файл не передается на внешние серверы конвертации. 
- Интерфейс должен корректно масштабироваться на экранах с разрешением от 1366x768 (старые офисные мониторы) без горизонтальной полосы прокрутки.
